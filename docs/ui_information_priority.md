# UI 정보 표기 중요도

이 문서는 기본 탐색 화면에서 어떤 정보를 얼마나 강하게 보여줄지 정리한다. 기준은 플레이어가 한 화면에서 받는 정보량, 생존 판단 속도, 시선 흐름이다.

## 기본 원칙

- 생존에 직결되는 정보는 압축하지 않는다.
- 행동 결정에 필요한 정보는 선택한 대상 가까이에 둔다.
- 관리성 정보는 기본 화면에 상시 노출하지 않고 메뉴, 탭, 오버레이로 보낸다.
- 로그와 상세 설명은 플레이어가 원할 때 열람하게 하고, 즉시 결과는 짧은 피드백으로 먼저 보여준다.
- 같은 정보를 여러 영역에서 같은 무게로 반복하지 않는다.

## 중요도 등급

| 등급 | 의미 | 표기 방식 |
| --- | --- | --- |
| S | 생존 실패, 행동 불가, 즉시 판단에 직결 | 항상 표시, 큰 대비, 수치/미터 병행 |
| A | 다음 행동 선택에 직접 필요 | 선택/상황 발생 시 명확히 표시 |
| B | 판단을 돕는 맥락 정보 | 짧은 문장, 칩, 툴팁으로 표시 |
| C | 관리/정리/최적화 정보 | 메뉴, 탭, 오버레이 중심 |
| D | 기록/상세 설명/반복 정보 | 접힘, 로그, 상세 패널 중심 |

## S 등급: 항상 명확히 보여야 하는 정보

| 정보 | 이유 | 권장 위치 | 권장 표기 |
| --- | --- | --- | --- |
| 체력 | 0에 가까워지면 즉시 게임 오버와 연결 | 플레이어 패널 | 미터 + 숫자 + 위험색 |
| 기력 | 행동 가능 여부와 비용 판단에 직접 영향 | 플레이어 패널 | 미터 + 숫자 + 위험색 |
| 허기 | 장기 생존과 상태 악화의 핵심 원인 | 플레이어 패널 | 미터 + 숫자 + 위험색 |
| 수분 | 가장 빠르게 위험해지는 생존 자원 | 플레이어 패널 | 미터 + 숫자 + 위험색 |
| 현재 위치 | 이동/채집/휴식 판단의 기준 | 맵 중앙 | 플레이어 마커, 선택 강조 |

| 행동 가능 여부 | 지금 실행 가능한지 결정 | 선택 타일 주변 컨텍스트 | 버튼 활성/비활성, 비용 표시 |

### 생존 4수치 표기 원칙

체력, 기력, 허기, 수분은 압축 칩으로 대체하지 않는다. 이 네 가지는 플레이어가 매 턴 확인해야 하는 핵심 자원이므로 기본 화면에서 미터와 숫자를 함께 보여준다.

권장 형태:

```text
체력  82  [████████--]
기력  46  [████------]
허기  31  [███-------]
수분  24  [██--------]
```

위험 기준:

| 값 | 상태 | 표시 |
| --- | --- | --- |
| 71-100 | 안정 | 기본색 |
| 41-70 | 보통 | 기본색 또는 약한 주의 |
| 21-40 | 주의 | 주황 계열 강조 |
| 0-20 | 위험 | 붉은 계열 강조, 상태칩 병행 |

## 현재 개편 방향

유지할 점:

- 생존 4수치는 기존처럼 미터 기반으로 명확히 보여준다.
- 인벤토리, 제작, 거점, 로그는 기본 화면에서 낮은 비중으로 두고 필요할 때 연다.
- 행동 실행은 맵 주변 컨텍스트 메뉴에 모은다.
- 하단 패널은 선택 타일을 해석하는 역할에 집중한다.

주의할 점:

- 정보압축은 생존 수치가 아니라 관리성 정보에 적용한다.
- 필드/인벤토리 간 이동처럼 조작 자체가 핵심인 정보는 텍스트 요약으로 대체하지 않는다.
- 위험 정보는 숨기지 않고 색, 미터, 상태칩으로 반복 확인 가능하게 둔다.
- 같은 정보가 상단, 하단, 사이드에 동시에 강하게 뜨지 않도록 한다.
