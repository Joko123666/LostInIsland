# Current Game State

갱신일: 2026-06-01

이 문서는 현재 저장소 기준의 시스템 구조와 UI 상태를 요약한다. 기준 파일은 `project.godot`, `scenes/main/Main.tscn`, `scripts/ui/main.gd`, `scripts/managers/*.gd`, `scripts/ui/draggable_item_card.gd`, `scripts/ui/item_drop_zone.gd`, `data/**/*.tres`, `assets/generated/**`이다.

와이어프레임:

- `docs/wireframes/current_game_state_wireframe.png`
- 루트 호환 파일: `WIREFREAME_01.png`

## 핵심 방향

이 게임 UI의 목표는 숫자 관리형 생존 화면이 아니라, 맵 위에서 생활과 감정, 위험을 동시에 읽게 하는 것이다.

- 생존에 직결되는 몸/숨/허기/수분은 압축하지 않고 미터와 숫자로 항상 보여준다.
- 필드/인벤토리 이동은 조작 자체가 핵심이므로 텍스트 요약이 아니라 드래그 가능한 카드와 드롭존으로 유지한다.
- 관리성 정보는 메뉴와 오버레이로 보내되, 행동 판단에 필요한 정보는 맵, 선택 타일, 캐릭터 패널 가까이에 둔다.
- 텍스트만으로 약한 결과는 컷인, 토스트, 카드 이동, 시간/날씨 전환 배너, 상태 이미지로 보강한다.

## 현재 화면 구조

메인 화면은 좌측 플레이어, 중앙 월드맵, 우측 동행자, 하단 선택 타일 정보로 나뉜다.

- 상단: 날짜, 시간, 날씨를 압축 표시하고, 중앙에는 시간 흐름 HUD가 있다. 시간대나 날씨가 바뀌면 이미지가 깔린 전환 배너가 잠깐 나타난다.
- 좌측 플레이어: 캐릭터 이미지, 상태 문장, 상태칩, 몸/숨/허기/수분 미터, 소지품 드롭존, 드래그 가능한 아이템 카드, 장비 벨트, 무게 표시가 있다.
- 중앙 맵: 10x10 헥스 타일 월드맵이다. 현재 위치 중심 카메라, 안개, 밤 시야, 날씨 레이어, 바람/안개 움직임, 타일 배지, 필드 아이템 표시가 들어간다.
- 맵 선택: 타일을 누르면 원형 행동 메뉴가 열리고, 중앙에는 위험/자원/거점/지형을 암시하는 이미지 미리보기가 깔린다.
- 하단: 선택 타일의 `정보` 탭과 `필드` 탭을 제공한다. 필드 탭은 현재 타일 드롭존과 필드 아이템 카드로 구성된다.
- 우측 동행자: 미합류 상태는 낮은 비중으로 표시하고, 합류 후에는 상태/관계/위치/반응 말풍선/소지품 드롭존을 보여준다.
- 좌상단 아이콘 메뉴: 인벤토리, 도구, 제작, 지도, 거점, 로그, 설정 진입점이다.
- 오버레이: 상태 상세, 아이템 사용, 제작/낚시/사냥 미니게임, 거점 화면, 이벤트, 컷신, 수면/하루 요약이 별도 레이어로 열린다.

## 인벤토리와 드래그/드랍

현재 조작 기준은 카드형 아이템 이동이다.

- 플레이어/동행자 소지품은 캐릭터 패널에서 드래그 가능한 카드로 표시된다.
- 카드 드래그 시 `draggable_item_card.gd`가 `item_stack` 데이터를 만들고 전체 드롭존에 하이라이트를 요청한다.
- 필드, 플레이어 인벤토리, 동행자 인벤토리, 거점 보관, 거점 직접 배치가 드롭 대상이다.
- 드롭이 끝나면 `main.gd::_on_item_drop_requested()`가 이동 방향을 판정하고, 성공 시 카드 이동 아크와 획득 토스트를 보여준다.
- 전체 목록, 정렬, 사용/넘김/버리기 버튼은 인벤토리 메뉴에 남아 있다.

주의: 필드/인벤토리 간 이동처럼 조작성이 핵심인 정보는 다시 텍스트 요약으로 압축하지 않는다.

## 게임 루프

- 시작 상태: 1일차 아침, 해변 타일 `tile_2_7`, 기본 소지품 `열매 x2`, `식수 x1`, `생존 가이드 x1`, 선택 초기 물품 1개.
- 시작 선택지: `생존도끼`, `구급키트`, `오락기`, `라이터`.
- 첫 목표: 현재 해변 조사, 물/먹을거리 확보, 주변 안개 해제, 동굴 거점 후보 확인, 초원 이동 시 파트너 재회.
- 행동은 30분 슬롯 단위로 시간을 소비한다.
- 야간에는 조사/제작 제한과 시간/기력 비용 증가가 적용된다.
- 행동과 시간 경과에 따라 허기와 수분이 줄고, 상태 이상과 기분이 변한다.
- 생존 가이드는 DAY 1~3 목표를 현재 상태에 맞춰 보여주며, 초반에는 로그와 감각 토스트로 다음 행동을 짧게 제안한다.

## 맵과 타일

- 월드 데이터는 `WorldManager`의 10x10 `terrain_layout`에서 생성된다.
- 표시 이미지는 `assets/tiles/region_hex/tile_x_y.png`를 사용한다.
- 주요 지형은 해변, 초원, 숲, 강가, 습지, 동굴, 바위 언덕, 유적이다.
- 조사 완료 타일의 인접 타일만 안개가 걷힌다.
- 일부 타일과 간선은 막힌 경로로 처리된다.
- 타일에는 위험도, 조사도, 개발도, 자원, 자원 오브젝트, 필드 아이템, 사냥/덫, 기억 배지가 표시된다.
- 위험/자원/거점/지형 이미지는 선택 컨텍스트 미리보기와 컷인에서 보조 신호로 사용된다.

## 제작과 거점

- 제작은 도구, 부품, 음식/요리, 설비, 가구 계열로 나뉜다.
- 제작 화면은 재료, 시간/기력 비용, 도구 조건, 제작 버튼을 제공한다.
- 일부 제작은 손작업 미니게임으로 품질과 실패를 판정한다.
- 거점은 동굴 타일에서 진입하며, 진입/퇴장에 짧은 페이드/슬라이드 전환이 있다.
- 거점 화면은 `base_growth/*` 이미지로 성장 단계를 보여주고, 쉼/온기/물/작업/보관/비바람 상태를 생활 단서로 표시한다.
- 거점 안에서도 날짜/시각/날씨 칩을 유지한다.

## 동료 시스템

- 파트너는 초원 계열 진입 이벤트로 합류한다.
- 기본 모드는 동행이며, 대화 메뉴에서 분리/합류를 제어한다.
- 동행 중 공동 행동은 위험을 낮추고 기력 분담과 짧은 반응 연출을 만든다.
- 따로 행동할 때는 동료 위치가 유지되며, 다시 합류하려면 같은 타일에서 대화해야 한다.
- 동료 상태는 말풍선, 관계 문구, 감정 이미지, 조언으로 전달된다.

## 이벤트와 컷신

- 이벤트 데이터는 `EventData` 리소스를 사용한다.
- 이벤트는 자동 컷신, 선택지 후 컷신, 일반 이벤트 패널을 지원한다.
- 컷신은 배경, 좌우 인물 이미지, 포커스, 화자, 대사, 톤, 플래시, 흔들림을 가진다.
- 컷신 레이어는 클릭/Enter로 진행하고 Esc로 종료한다.

## 검증 상태

- Godot 헤드리스 에디터 로드로 스크립트 파싱과 PNG import를 확인했다.
- `scripts/tests/three_day_survival_smoke.gd`가 `THREE_DAY_SURVIVAL_SMOKE_OK`를 출력한다.
- 현재 폴더는 Git 저장소로 인식되지 않아 `git status` 기반 변경 추적은 사용할 수 없다.

## 장점

- 맵 중심 플레이 구조가 명확하고, 타일 선택에서 행동까지 흐름이 짧다.
- 생존 4수치, 캐릭터 이미지, 상태 문장, 카드형 인벤토리, 필드 드롭존이 한 화면에서 연결된다.
- 시간/날씨/안개/조명/컷인이 생존 판단과 분위기를 함께 만든다.
- 드래그/드랍으로 필드, 인벤토리, 거점, 파트너 간 아이템 이동이 직관적으로 작동한다.
- 컷신과 생성 이미지 자산 연결 구조가 있어 이벤트 연출 확장이 쉽다.

## 단점과 위험

- `main.gd`가 매우 커져 UI 유지보수와 회귀 위험이 높다.
- 타일별 고유 랜드마크는 아직 제한적이고, 지형 대표 이미지가 완전한 장소 기억을 대체하지는 못한다.
- 일부 메뉴/오버레이 전환은 아직 즉시 표시 위주라 시각적 일관성이 부족하다.
- 사운드, 접근성 옵션, 키보드/패드 조작은 아직 정교하지 않다.
- 스모크 테스트는 기본 3일 루프 중심이라 나쁜 운, 다른 시작 아이템, 동료 분리 루트까지 충분히 덮지는 않는다.

## 다음 개선 제안

1. `main.gd`를 `map_panel`, `character_panel`, `inventory_drag`, `feedback_layer`, `base_view`, `cutscene_layer` 단위로 분리한다.
2. 중요 타일 6~10개를 고유 랜드마크 이미지와 사건 기억을 가진 지점으로 승격한다.
3. 드래그 대상 확장을 타일, 자원 오브젝트, 파트너, 거점 시설까지 일관되게 정리한다.
4. 시간/날씨 전환과 위험 발생에 사운드 큐를 추가한다.
5. 3일 생존 스모크에 실패 루트, 비/폭풍 루트, 다른 시작 아이템 루트를 추가한다.
