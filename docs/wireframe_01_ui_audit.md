# WIREFREAME_01 UI/UX Audit

갱신일: 2026-06-01

와이어프레임 파일:

- `WIREFREAME_01.png`
- `docs/wireframes/current_game_state_wireframe.png`

## 객관 평가

### 장점

- 월드맵이 여전히 가장 큰 화면 영역을 차지해, 탐험과 이동 판단이 중심에 놓인다.
- 플레이어와 동행자 패널이 맵 양쪽에 고정되어 행동 중에도 생존/관계 정보를 잃지 않는다.
- 몸/숨/허기/수분은 미터와 숫자로 다시 명확하게 보이며, 압축하지 않는다.
- 인벤토리는 텍스트 요약이 아니라 드래그 가능한 카드와 드롭존으로 복구되어 필드/인벤토리 이동이 직관적이다.
- 선택 타일 주변의 원형 행동 메뉴와 하단 정보 패널이 역할을 나눈다.
- 시간 흐름, 날씨, 안개, 컷인, 감각 토스트, 카드 이동이 행동 결과를 보조한다.
- 생성 이미지 자산이 시간 전환, 위험 경고, 거점 진입, 제작/행동 컷인에 배치되어 텍스트 의존도가 줄었다.

### 단점

- 화면 정보량은 줄었지만 `main.gd` 하나가 UI 대부분을 담당해 구조적 복잡도는 높다.
- 타일 선택 컨텍스트에 행동 버튼, 이미지 미리보기, 동료 조언이 동시에 뜰 수 있어 일부 상황에서는 시선이 분산될 수 있다.
- 동행자 미합류 상태의 우측 패널은 낮은 비중으로 정리되었지만, 합류 후에는 상태/관계/소지품/대화가 몰릴 가능성이 있다.
- 인벤토리 카드 복구로 조작성은 좋아졌지만, 작은 화면에서는 사이드 패널 세로 스크롤 부담이 다시 생길 수 있다.
- 시간/위험/컷인 연출은 시각적으로 강화되었지만 아직 사운드나 접근성 옵션과 연결되지 않았다.

## 현재 와이어프레임 반영 사항

- 상단: 날짜/시간/날씨 압축 셀과 중앙 시간 흐름 HUD를 유지한다.
- 상단 전환: 시간대/날씨 변화 시 이미지 배경이 들어간 전환 배너가 맵 위에 뜬다.
- 좌측 플레이어: 캐릭터 이미지, 상태 문장, 몸/숨/허기/수분 미터, 소지품 카드 드롭존, 장비/무게 표시를 배치한다.
- 중앙 맵: 10x10 헥스 타일, 현재 위치 중심 카메라, 안개, 밤 시야, 날씨/바람/조명 레이어를 표시한다.
- 타일 선택: 선택 타일 주변에 원형 행동 메뉴를 띄우고, 중앙 미리보기에는 위험/자원/거점/지형 이미지를 넣는다.
- 하단 패널: `정보`와 `필드` 탭을 분리한다. 필드 탭은 드래그/드랍 이동 대상이다.
- 우측 동행자: 미합류 상태는 낮은 비중으로, 합류 후에는 관계/상태/대화/소지품 드롭존을 표시한다.
- 결과 피드백: 행동 컷인, 생존 변화 토스트, 아이템 획득 토스트, 카드 이동 아크를 사용한다.
- 거점: 진입/퇴장 전환과 거점 성장 이미지를 사용한다.

## 적용된 수정

- 생존 핵심 수치인 몸/숨/허기/수분을 미터 + 숫자 표시로 유지한다.
- 사이드 인벤토리를 텍스트 요약에서 드래그 가능한 카드 그리드로 되돌렸다.
- 필드/인벤토리/파트너/거점 간 이동을 드롭존 중심으로 유지한다.
- 시간 전환 배너를 추가하고 `time_weather/*`, `ui_transition_effects/time_shift.png`를 연결했다.
- 타일 선택 컨텍스트에 위험/자원/지형 미리보기 이미지를 배치했다.
- 행동 컷인에 물, 식량, 위험, 거점, 제작 전환 이미지를 연결했다.
- 생존 수치가 크게 악화될 때 `survival_status/*` 이미지를 토스트 아이콘으로 쓴다.
- 거점 진입/퇴장에 짧은 페이드/슬라이드 전환을 추가했다.

## 더 좋은 방향

1. `scripts/ui/main.gd`를 기능별 UI 스크립트로 나눈다.
2. 작은 화면에서 사이드 인벤토리 카드가 과밀해지는지 실제 해상도별 스크린샷으로 점검한다.
3. 드래그 대상 가능/불가능 상태를 더 강한 시각 언어로 통일한다.
4. 시간 전환, 위험 발생, 거점 성장에 사운드 큐를 붙인다.
5. 동행자 합류 후 우측 패널의 정보 밀도를 다시 한 번 점검한다.
